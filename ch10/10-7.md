# 10.7 モナドなど

* 「モナド」とは、プログラミングパターンの1つで、「モナディック」な関数を直列につなげることができるもの
  * 「モナディック」な関数とは、「通常」の値を受け取り、ある種の「拡張」された値を返す関数
      * 本書でこれまで扱ってきた例としては、拡張された値＝Result型でラップされた値
* 「モナド」は、技術的には次の3要素を持ったもの
  1. データ構造
  2. 関連するいくつかの関数（returnとbind）
  3. 関数がどのように動作しなければいけないかについてのいくつかのルール（＝モナド則）

```fs
// --------------------------------------------------------
// 1. データ構造
// --------------------------------------------------------
type Result<'Success, 'Failure> =
  | Ok of 'Success
  | Error of 'Failure

// --------------------------------------------------------
// 2. returnとbind
// --------------------------------------------------------
// returnは、通常の値をモナドに包む関数
let ret x = Ok x

// bindは、モナドの値にモナディック関数をつないでいける関数
let bind m f =
    match m with
    | Ok x -> f x
    | Error e -> Error e

// --------------------------------------------------------
// 3. モナド則
// --------------------------------------------------------
// 3.1. 通常の値をモナドに包んでから f に渡すのは、最初から f に渡すのと同じ
bind (ret x) f == f x

// 3.2. モナドの値にreturnを適用しても、何も変わらない
bind m ret ==  m

// 3.3. 2つの関数を続けてbindするのは、これらの関数から決まる1つの関数をbindするのと同じ
bind (bind m f) g  ==  bind m (\x -> bind (f x) g)

```

## 10.7.1 アプリカティブを使って並列に合成する

* モナディック関数を直列につなげるのではなく、並列に組み合わせることが可能になる
* 本書のモナディックなアプローチでは、バリデーションエラーが発生した際に最初のエラーしか残せないが、すべてのエラーを結合できるようになる
